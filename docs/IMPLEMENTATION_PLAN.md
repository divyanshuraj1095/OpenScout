# Approval gates

Implement only the individually approved row. Each phase ends with actual build/test output, changed files, flow walkthrough, verification instructions, limitations and a suggested commit.

| Phase | Work and acceptance check |
|---|---|
| 0 Audit | Review six documents against routes, migrations and UI service types. Confirm documentation-only diff. |
| 1 Foundation | Maven wrapper, Java 21, Boot parent and Spring AI BOM, Flyway dev schema, bcrypt, cookie JWT, CSRF, profile. Run mvnw verify with Postgres Testcontainers. Exercise signup/login/profile/logout, bad CSRF and expired/revoked sessions. |
| 2 Parity | Port import, refresh, filters, pagination, profile, search and bookmarks. Fetch all GitHub Link pages with shared auth, exclude PRs, request all states, stage complete results before transactional upsert. Never infer closure from a partial response. Test two users importing one repo, concurrent bookmarks, updated and closed issues, failed page two and Advanced label rules. |
| 3 RAG sample | Embed a small labeled fixture with Ollama, inspect SQL ranks, prompt and returned chunk IDs. Run same adapter contract with configured hosted provider before production. Known question cites expected lines, unsupported question abstains. |
| 4 Indexing | Implement persistent leased jobs and atomic promotion. Kill worker mid-batch, resume, inject 429 and change one file. Verify old index stays readable, deleted file disappears and unchanged content needs no embedding call. |
| 5 Grounded interactions | Add issue explanation and chat with validated citations. Reject fabricated IDs, cross-user sessions and cross-repo evidence. Test hostile instructions as inert text. |
| 6 Redis | Scope cached results by visibility, model, index and query; isolate personal data by principal. Authorize every hit. Exercise expiry, index rollover, atomic quota counters and cache outage. Fail closed on unavailable spend limiter. |
| 7 Discovery | Combine lexical and vector rankings using reciprocal rank fusion. Rank member-visible issues by preferences. Compare against lexical-only and semantic-only results on labeled queries; verify isolation and cold-start fallback. |
| 8 Frontend | Adapt existing service modules to v1, retain pages/hooks/components. Add job polling, source links, semantic search and repository chat. Verify both API modes on separate environments, authentication, bookmarks, failed indexing and empty evidence. |
| 9 Evidence | JUnit/Mockito isolate policy and provider boundaries. Testcontainers exercises real constraints, Redis and pgvector. Freeze labeled queries and measure recall@k, citation validity, abstention and leakage. k6 measures p50/p95, throughput and failures under documented concurrency, corpus and hardware. Agree latency/quality targets before measurement; require zero scope violations and invalid returned citations. |
| 10 Release | Docker multi-stage build, local Compose, Actions build/test/image checks, Actuator/Micrometer metrics, private Prometheus and Grafana dashboards. Rehearse restore, worker restart, secret rotation, rollback and health checks in staging before separate production approval. |

Keep Node and React runnable through the migration. Use a distinct API origin and database in development. Compare parity with fixtures before switching frontend configuration. Avoid dual writes. Deployment remains single-region/single-host unless availability requirements fund redundancy.
Before each optimization freeze inputs and collect the control. Phase 2 compares Node vs Spring import and sequential vs batch writes; Phase 3 collects generic LLM correctness before RAG; Phase 4 compares full vs incremental and per-user vs shared indexing; Phase 6 compares Redis off/on; Phase 7 compares keyword, vector and hybrid. Create benchmarks/ and docs/BENCHMARKS.md when collection begins. Use identical repository snapshots, user sets, labeled questions, model settings and comparable concurrency; record hardware, environment, dataset sizes, warm-up, repetitions, errors and raw results. Calculate improvements only from measured comparable observations. Phase 9 repeats these experiments.
